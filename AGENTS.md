# Custom Agent Guidelines

## Brand Assets & Guidelines

### 1. DigiLend Logo Locking Rule
- **Locked Asset**: The current **DigiLend** logo is the official brand logo and must remain exactly as it currently is.
- **Scope of Protection**: Whenever implementing new features, UI improvements, redesigns, bug fixes, layout updates, background adjustments, animations, or any full rebuilds, **do not remove, replace, regenerate, or modify the logo**.
- **Appearance Consistency**: The logo's icon, colors, typography, styling, proportions, and overall appearance must remain perfectly unchanged across all screens and future iterations.
- **Universal Application**: All screens, including onboarding, login, dashboard, loan application sequences, profile pages, support pages, and admin diagnostics panels, must display this specific approved logo.
- **Automatic Recovery**: If any future automated update or layout shift accidentally affects the logo, immediately restore the original logo implementation instead of generating a new one.
- **Exception Clause**: Only replace, redesign, or modify the logo if the user explicitly gives a direct instruction, such as: `"Replace the DigiLend logo"`.
